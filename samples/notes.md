# 现场记录：批量改键之后注释全没了（摘录）

- 时间：2026-09-14 21:40 起，处理到次日 03:10。
- 来源：值班组用组里的老脚本，给 12 台机器改 `[server]` 的 `port` 与 `[retry]` 的 `max`。
- 现象：跑完之后运维手写的说明全部消失，只剩节头与键值行；第二天早上要查「这套配置当初为什么这么写」，一条注释都找不到。

同事留的改前改后对照（节选）：

    改前：
    # 网关服务配置（运维手工维护，请勿重排）
    [server]
    listen = 127.0.0.1        # 仅监听本机
    port = 8080               # 生产端口，改动要走变更单
    timeout = 30 \
           seconds

    改后：
    [server]
    listen = 127.0.0.1
    port = 9090
    timeout = 30 seconds

对齐用的空格、行尾注释、续行、缩进被一律「顺平」；文件末尾还多出一个空行。
有一台机器上 `[retry]` 里 `max` 出现过两次，老脚本只改了第一处，结果生效的仍然是旧值，当晚又多排查了一个小时。
回滚靠备份，代价是一个通宵。

现场结论：注释与排版是运维的活文档，改键就只能动键，其余字节一个都不能碰。
本文件只记录现象，判定口径与输出格式以 `README.md` 为准。
